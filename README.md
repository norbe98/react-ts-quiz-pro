# Quiz App

A React quiz application built with TypeScript and Tailwind CSS.

## Features
- 3 difficulty levels (Easy, Medium, Hard)
- 10 questions per round from Open Trivia DB
- 10-second timer per question
- Score history saved to localStorage
- Fully responsive design

## Tech Stack
- React 18 + TypeScript
- React Router v6
- Tailwind CSS
- Vitest
- Context API for state management
- Open Trivia DB API

## Run locally
\`\`\`bash
npm install
npm run dev
